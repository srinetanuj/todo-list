# Todo List

A simple todo list app - add, mark complete, and delete tasks.

- How to Use

1. Open `index.html` in your browser
2. Type a task and click + (or press Enter)
3. Click Done to mark complete
4. Click Delete to remove
5. Tasks auto-save to browser storage

- Features

- Add tasks (min 3 characters)
- Mark done
- Delete tasks
- Auto-saves to browser
- Works on mobile & desktop

- Files

- `index.html` - Main app
- `script.js` - Functionality
- `styles.css` - Styling

- Validation

- Minimum 3 characters required
